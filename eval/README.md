# Manual evaluation protocol

Run `ewu-kb review` after ingestion to prepare local review files. They are ignored by Git because review pages contain original personal information and answers must remain independent of model results.

1. **Topics:** in `annotation_sample.csv`, read each of 100 passages and fill `human_topic` using [the topic label guide](TOPIC_LABEL_GUIDE.md), plus `reviewer`. The rule label is a comparison, not the ground truth. Record disagreements. If rules are tuned on these examples, report final agreement as descriptive training-sample agreement, not held-out accuracy.
2. **PII:** open local `work/pii_review.html`, independently select every person name, email, phone and student ID. Copy Unicode character offsets into `pii_annotations.csv` (`sample_id,start,end,type,reviewer,notes`). Mark every page in `pii_pages.csv` reviewed `yes`, including pages with no PII. Do not inspect detector predictions until annotation is complete. Twenty-four physical PDF pages include faculty-rich pages and random pages. This deliberate mixture is not a population prevalence sample. Do not tune thresholds on the final test sample; create a separate development set if tuning is needed.
3. **Retrieval:** `questions.csv` contains 40 draft prompts without answers. Verify that each is answerable in the collected snapshot. Edit unsupported questions before freezing. Read official sources independently; supply `expected_doc` and `expected_page` (physical PDF page, multiple accepted pages separated by `|`) or `expected_section` (a distinctive exact section-path substring for HTML). Fill `reviewed=yes` and `reviewer`. Do not use search rankings to choose gold answers. Run `ewu-kb freeze-questions` before `ewu-kb evaluate`. The lock prevents later changes.

Report Recall@1, Recall@5 (question hit rate) and MRR@20 on the frozen questions. The primary comparison applies no gold topic filter or web preference bonus. Compare both models at nominal sizes 200 and 300; the shared cap for the second setting is 254 content tokens and both tokenizers are checked. Results are a small, domain-specific evaluation, not a general capability claim.

Run `ewu-kb evaluate` then `ewu-kb report` after completing the files. Missing human labels produce explicit pending states, never invented scores. The original review set and frozen questions should be kept unchanged as evidence. Publish only a separately reviewed redacted sample and aggregate results.
